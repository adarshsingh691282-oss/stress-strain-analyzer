# Stress-Strain Analysis & Material Property Solver

A Python computational tool designed to model and analyze engineering stress-strain curves from tensile tests, determining critical mechanical properties like Young's Modulus, Yield Strength, and Ultimate Tensile Strength (UTS).

## 📌 Engineering Principles
- **Hooke's Law (Elastic Region):** $\sigma = E \cdot \epsilon$
- **Young's Modulus ($E$):** Slope of the elastic deformation zone.
- **Yield Strength ($\sigma_y$):** Stress threshold where plastic deformation begins.
- **Ultimate Tensile Strength (UTS):** Maximum stress point sustained prior to necking.
